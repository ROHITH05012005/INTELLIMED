# INTELLIMED - SMART MEDICINE RECOMMENDATION SYSTEM

INTELLIMED is an intelligent healthcare solution integrating IoT hardware, edge computing, machine learning, and modern web interfaces to deliver smart medicine recommendations, patient monitoring, and medication dispensing.

## Project Structure & Branches

This repository follows a structured branch workflow:

- `main` - Stable, production-ready releases.
- `develop` - Integration branch for ongoing development.
- `feature/esp32-firmware` - ESP32 microcontroller code, IoT sensors, and device communication protocols.
- `feature/hardware` - Circuit diagrams, schematics, PCB designs, and physical CAD models.
- `feature/ml-model` - Machine learning pipelines, disease-medicine recommendation models, and training notebooks.
- `feature/data-analysis` - Healthcare datasets exploratory data analysis (EDA), preprocessing, and statistical insights.
- `feature/backend` - Server APIs, database integration, authentication, and communication gateways.
- `feature/frontend` - Responsive web dashboard and user portal.
