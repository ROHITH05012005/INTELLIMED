# Feature Dictionary

## Purpose

This dictionary describes the engineered features available in the processed and ML-ready exports generated by the reproducible feature-preparation pipeline.

## Core event columns

- `patient_id`: patient identifier
- `medicine_id`: medicine identifier
- `medicine_name`: medicine label
- `compartment_id`: smart-box compartment slot
- `scheduled_date`: planned medication date
- `scheduled_time`: planned medication time
- `reminder_time`: reminder trigger time
- `acknowledged_time`: actual completion or acknowledgment time
- `delay_minutes`: schedule delay in minutes
- `dose_status`: final medication outcome (`TAKEN`, `PENDING`, `MISSED`)
- `day_of_week`: derived weekday
- `time_period`: time bucket (`MORNING`, `AFTERNOON`, `EVENING`, `NIGHT`)
- `frequency`: dosing schedule frequency
- `dose_quantity`: dose amount or count
- `previous_missed_doses`: historical missed events before the current record
- `previous_taken_doses`: historical taken events before the current record
- `adherence_percentage`: historical adherence rate for the patient or medicine context
- `sensor_event`: device or sensor interaction event

## Temporal features

- `scheduled_hour`: hour-of-day for the scheduled dose
- `scheduled_minute`: minute-of-hour for the scheduled dose
- `scheduled_hour_sin`: sine encoding of the scheduled hour
- `scheduled_hour_cos`: cosine encoding of the scheduled hour
- `day_of_week_numeric`: Monday-Sunday encoded as integers
- `is_weekend`: binary signal for Saturday/Sunday dosing
- `time_period_encoded`: categorical time-period encoding as integers

## Historical and rolling features

- `previous_1_dose_status`: prior dose status value from the immediately preceding event
- `previous_3_dose_missed_count`: number of missed doses in the prior 3-dose window
- `previous_7_dose_missed_count`: number of missed doses in the prior 7-dose window
- `previous_7_dose_adherence`: adherence percentage across the prior 7-dose window
- `previous_30_dose_adherence`: adherence percentage across the prior 30-dose window

## Validation metadata

- `is_valid_record`: boolean flag indicating whether the row passed the dataset validation checks
- `validation_issues`: semicolon-delimited summary of any flagged issues for the row

## Usage guidance

These engineered features are intended for downstream analytics and future ML work. They should be created from information that is available before the current event outcome is finalized to avoid leakage from the target signal.
