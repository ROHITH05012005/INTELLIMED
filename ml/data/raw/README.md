# Synthetic Medication Test Data

This folder contains a small synthetic dataset used only for testing the data analysis and EDA workflow.

## Important notice

SYNTHETIC — NOT REAL PATIENT DATA

This dataset is created for software testing, data validation, and analysis workflow verification only. It is not a real medical dataset and must not be used for patient care, clinical diagnosis, or medical claims.

## Purpose

- validate schema loading
- test missing-value detection
- test duplicate and invalid-status detection
- validate adherence calculations
- confirm plotting and reporting logic
- provide a clean data handoff to future ML work

## File

- `sample_synthetic_medication_data.csv`

## Data usage restriction

- no patient names or real identifiers are included
- no real treatment history is represented
- no conclusions about health outcomes should be drawn from this dataset
